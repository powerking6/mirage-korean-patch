# RainBlood Chronicles: Mirage 비공식 한글패치

중국어 원문을 기준으로 번역한 Steam Windows판 한글패치입니다.

## 다운로드

[최신 배포본 받기](https://github.com/powerking6/mirage-korean-patch/releases/latest)

Releases의 **Mirage_Korean_1.0.0.zip**을 받으세요. GitHub가 자동으로 제공하는 Source code ZIP은 설치 파일이 아닙니다.

## 지원 버전

- Steam Windows판 / AppID 240660 / 빌드 140809
- Windows 10/11 x64, .NET Framework 4 이상
- 게임 파일 쓰기 권한과 작업 공간 약 3GB 필요

## 설치

1. 게임을 종료합니다.
2. ZIP을 풉니다. 압축 최상위에 EXE와 안내문이 바로 있으며 별도 하위 폴더는 없습니다.
3. `Mirage_KoreanPatch_v1.0.0.exe`를 실행합니다.
4. `Mirage.exe`가 있는 게임 설치 폴더를 선택하고 **한글패치 설치**를 누릅니다.
5. Steam에서 게임 언어를 **영어(English)**로 설정한 뒤 실행합니다.

원본 파일은 게임 폴더의 `.MirageKoreanPatchBackup/v1.0.0`에 자동 백업됩니다. 복원할 때 필요하므로 보관하세요. EXE를 게임 설치 폴더에 두고 실행해도 됩니다. Python, xdelta 등의 별도 설치나 인터넷 연결은 필요하지 않습니다.

## 원본 복원

같은 EXE에서 게임 폴더를 선택하고 **원본 복원**을 누릅니다. 백업이 없다면 Steam 파일 무결성 검사로 원본을 복구할 수 있습니다. 설치기는 원본·패치 파일의 SHA-256을 검사하며 다른 버전의 파일은 변경 전에 차단합니다.

## 포함 내용

- 대사·문서·도감·무공·아이템·업적·상점·로딩 번역
- 중국어 기준 인명·지명·무협 용어와 한자 병기
- UI·지도·장 제목·보스 등장 이름 이미지 교체
- 원래 튜토리얼 및 무공 조작 그림을 유지한 한글 안내
- 1인용 설정 키를 읽는 튜토리얼 키 표시
- 검은 붓글씨 `死` 사망 연출

세이브 및 진행도 해금 파일은 포함하지 않으며, 설치·복원 중 세이브를 수정하지 않습니다. 전체 게임 파일 대신 원본과의 차이만 담은 패치입니다.

## 검수 상태

AI 번역 및 후속 검수를 거쳤습니다. 사용자 플레이 검수에서 확인한 전투·UI·교체 이미지는 정상 표시되었습니다. 전체 구간의 플레이 검수를 완료했다는 의미는 아니며 오역이나 누락이 남아 있을 수 있습니다.

배포 EXE는 별도 원본 사본에서 84개 파일의 설치·재설치 확인·원본 복원과 변조 파일 차단을 시험했습니다. 미표시 기술명 4개는 임의의 기술 단계 해석을 피하기 위해 원문 상태로 유지했습니다.

문제가 있으면 Issues에 발생 화면·설명·스크린샷을 남겨 주세요.
